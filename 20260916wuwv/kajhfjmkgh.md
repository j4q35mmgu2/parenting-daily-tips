# 【科普】保护听力，终生受益

> 更新时间：2026-09-16 (UTC+8)

爱耳日

我国是一个人口大国，人口基数大则意味着发生听力损失障碍的人数也很大，据第二次全国残疾人抽样调查显示，全国约有2780万听力残疾人士，人数位居五大残疾之首，是世界上听障人数最多的国家。而每一千名新生儿中大概有1到3名为听力障碍，高发病率则导致听力障碍的人数还在持续增长，再加上人口老龄化的发展，老年性聋的人数也在不断增加。如何保护自己的听力，则变得尤为重要。**2020年3月3日是我国第21个“爱耳日”。****本次全国“爱耳日”宣传教育活动主题为“保护听力，终生受益”。**

听力损失分级

**据WHO-1997所设定的听力损失分级为：**
**正常听力：**≤25 dB HL，可以听到耳语声，日常生活交流无碍。**轻度听力障碍：**26-40 dB HL，可听到1米处的言语声，在嘈杂环境中听声可能存在困难。**中度听力障碍：**41-60 dB HL，可听到1米处大声的言语声，日常生活中的对话存在一定的困难。**重度听力障碍：**61-80 dB HL，需要对着叫喊才能听到部分言语，日常生活中有比较严重的沟通障碍。**极重度听力障碍：**≥81 dB HL，即使是大喊大叫，也听不到和听不懂，通常也不会说话。

如何保护听力

**远离噪声环境**。长期处于噪声环境下，容易导致听觉器官老化。如平时佩戴耳机时尽量每隔30分钟让耳朵休息一下，在工厂机器等噪声下工作应佩戴防噪声耳塞。

**避免乱挖耳朵。** 平时不要用小木棒、发夹等挖耳止痒，以防损伤耳道深处的鼓膜，引起鼓膜穿孔和化脓性中耳炎等病变，造成听力损失。

**避免使用耳毒性药物。****** 如链霉素、庆大霉素、卡那霉素、新霉素、奎宁及其衍生物等，以免发生药物中毒性耳聋。特别是已经明确诊断耳聋基因者。

**及时就诊。**对于已经发生的中耳炎或者听力下降者，应当及时到耳鼻喉科就诊，以防听力进一步下降。

**科学验配调试助听器**，对于佩戴助听器者，应根据听力损失情况，科学合理地验配和调试助听器，如通过自由声场、真耳分析和助听器效果评估量表等专业评估。

**保持健康的生活方式，劳逸结合。**同时积极治疗高血压、高血脂及糖尿病等。这些疾病易使内耳血运发生障碍而引起突聋。

儿童听力 

在孕前和孕早期夫妻两人可进行下一代耳聋基因的筛查检测，并通过遗传咨询减少严重耳聋缺陷儿童的出生；同时可避免药物和相关因素导致儿童的耳聋发生。

出生后的儿童应在新生儿期、3个月、6个月、1岁、2岁、3岁进行听力检查。如在任何时期儿童听力检查有异常，即按医生要求定期复查，及早进行干预和治疗，可以保证良好的沟通交流，促进他们获得教育、就业和社交的机会，让有听损的儿童也能正常融入到日常的社会活动中。
